AI reads and explains: listens, asks questions, sorts answers into task cards, researches the local market.

APIs: Anthropic API (Claude Opus 5.5) · RunPod serverless GPU (Whisper, task-card classifier, GLM-5.3) · LiveKit Cloud · certificate check uses our own rules, no AI. Data: Anthropic Economic Index, ILO, OpenDOSM, MyMAHIR, HRD Corp, MGTC.
